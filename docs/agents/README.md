# Agent documentation

This directory contains stable instructions for agents working in Sponsor Not Sponsor. Start at the repository `AGENTS.md`, then use this index.

| File | Use it for |
| --- | --- |
| `laya-workflow.md` | Current product, runtime, data, review, validation, and training-authorization flow. |
| `domain.md` | How to find and preserve authoritative domain terminology and decisions. |
| `issue-tracker.md` | GitHub issue operations and dependency conventions. |
| `triage-labels.md` | Mapping between generic triage roles and repository labels. |

The dated files under `evaluation/laya-training/` are evidence and handoffs, not replacements for this index. `HANDOFF.md` says what is current; historical reports explain how the project reached that state.

If instructions conflict, use this precedence:

1. Current user instruction.
2. `DECISION_LOGIC.md` for sponsorship meaning and headlines.
3. Versioned runtime contracts and acceptance criteria.
4. `HANDOFF.md` and the active contextual-v2 README for current state.
5. Historical plans, reports, and snapshots.

Never interpret a historical `approved` Boolean as current permission to train or promote a model.
