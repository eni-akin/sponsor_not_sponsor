## Installed runtime facts

Read directly from `.decision-venv/lib/python3.12/site-packages/laya/{agent,common}.py`, the cached base config, smoke checkpoint config, and all production questions:

- Every product question is `choice`, mapped to qtype 0. Runtime `temperature` accepts exactly three entries, ordered choice/score/noul. A fitted shared temperature exports as `[T, 1.0, 1.0]`; a five-field array is invalid.
- `_decode_answers` first selects `temperature_by_options[temp_bucket(qtype,k)]`, then falls back to `temperature[qtype]`. Scope's six options use `choice:6-10`; the other four questions use `choice:3-5`. Buckets cannot express five independent per-question temperatures. A shared scalar needs no runtime modification when bucket overrides are removed. Per-question fitting would require a separately tested runtime/worker change.
- The installed runtime clamps temperatures to **[0.5, 5.0]**. Fit within those bounds and record the effective temperature; fitting any positive scalar outside them silently produces different deployment probabilities. Detect/report a boundary optimum rather than claiming unrestricted optimality.
- `RLDecisionModel.forward` returns raw logits; its registered temperature buffer does not scale them. Calibration is applied during agent decoding, not by direct model forward. The cached base config currently has `[1,1,1]` and empty bucket mappings. Record that actual base config/hash rather than assuming inherited scaling is non-unit.
- Decoding rounds `probabilities` and selected `answer_confidence` to four decimals. The worker consumes that rounded selected probability. Fit temperature on raw logits, but search and verify abstention thresholds through the same rounded probabilities and production projection used by deployment. Full-precision threshold simulation can disagree around cutoffs.
- Smoke checkpoint config retains inherited upstream `training` statistics (15,987 updates/four epochs) alongside its actual `sns_training.updates: 1`. The domain artifact must explicitly distinguish inherited training history from its own resumable progress and selected checkpoint identity.
