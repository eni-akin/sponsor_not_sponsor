SPONSOR NOT SPONSOR

Read the evidence.

A guide to the preview and its limits.

Start with a single job

Open or reload a job posting. When the extension recognizes one role, a small badge appears. Click it to see separate sponsorship, CPT, and OPT findings, with supporting quotations.

Use the toolbar popup for Scan again, Show on page, pause, and site controls. The badge’s × hides it for the current role until reload; Show on page restores it. Escape closes the evidence panel.

Understand a finding

  • Available or unavailable: recognized wording explicitly offers or excludes sponsorship. Read any current/future timing.
  • Conditional: the wording includes exceptions or employer consideration.
  • Unclear: no supported policy was found, or wording is conflicting or needs review. An application question is not an offer.
  • CPT and OPT: each needs its own explicit evidence. A sponsorship refusal alone establishes neither.

Citizenship and other stated restrictions appear separately. Findings describe source wording, not your personal eligibility. Incomplete scans remain marked incomplete.

If a job is missed

Wait for the description to load, select a single vacancy, then try Scan again. Check that scanning is not paused or disabled for the site and that Chrome permits access. After updating the extension, reload the job tab.

The preview uses a limited set of English page and phrase rules. It can miss unusual wording, employers without readable metadata, jobs inside embedded frames, PDFs, and unsupported layouts. It does not carry findings from a posting to a separate application. It has not completed independent real-world accuracy validation.

Optional company research

Research is off by default and requires a separately running local service. With it enabled, an identified employer and an unclear sponsorship, CPT, or OPT finding trigger a lookup. Research sources appear separately and never change the page’s badge.

The supplied service currently includes only a verified Atlassian mapping, no historical dataset, and no preconfigured policy pages. Wider discovery needs a server-side search key and reviewed employer mappings. Missing employer details block research; JavaScript-only or blocked sources may be unreadable.

For the source distribution, start the service with pnpm research:serve, then enable research in the popup. The browser package alone does not install the service. If Chrome assigns a different extension ID, configure the service’s RESEARCH_EXTENSION_ID to match the ID shown in chrome://extensions and restart it.

Report an incorrect result

In the evidence panel, choose Report incorrect result, select the issue, and download the report. Nothing is sent automatically. Review the JSON before sharing: it contains the role, findings, quoted evidence, and a page address without query or fragment. The preview has no automatic support inbox.
