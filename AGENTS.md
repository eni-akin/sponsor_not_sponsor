## Project workflow

Before changing sponsorship logic, read `DECISION_LOGIC.md`. Read `HANDOFF.md` for current project status.

The published extension uses the existing deterministic interpreter and blocker-first headline. Preserve scanner, iframe, source-identity, overview-recovery, privacy, accessibility, and rule regressions when changing shared code. Keep sponsorship, CPT, OPT, and eligibility restrictions distinct.

Preserve unrelated working-tree changes. Verify implementation with `pnpm check` and affected browser suites. Authored fixtures and exposed development reviews do not establish independent real-world accuracy.
