Before contacting support

  • Wait for the job description to load, select one vacancy, then choose Scan again.
  • Check that scanning is not paused or disabled for the site and that Chrome allows site access.
  • After updating the extension, reload the job tab.

Report an incorrect result

In the evidence panel, choose Report incorrect result, select the issue, and download the JSON report. Review it before sharing: it contains role details, findings, quoted evidence, scan time, and a sanitized page address. It excludes the full page extraction and form answers. Nothing is sent automatically.

Known limits

The extension targets English-language U.S. job postings. It can miss unusual wording, employers without readable metadata, inaccessible pages, PDFs, and unsupported layouts. A result describes the posting's recognized wording; it is not legal advice, a personal eligibility decision, or proof that sponsorship is available.
