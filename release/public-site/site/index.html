Local analysis

Analysis runs in the browser. There are no accounts, ads, analytics, or active company-research service.

Quoted evidence

Results point back to exact posting language so people can review the source rather than rely on a hidden score.

Careful limits

A result describes recognized wording, not personal immigration eligibility or a guarantee of employer policy.

Publication status

This website package supports a release review but does not establish Chrome Web Store approval, independent real-world accuracy, legal advice, or trademark clearance.
