Privacy and data handling

Sponsor Not Sponsor reads page text in your browser to explain job requirements using deterministic rules. Company research is not active in this extension. There are no analytics, ads, or accounts.

Information the extension accesses

The extension has access to HTTP and HTTPS pages so it can recognize job postings automatically. It inspects the current page address, visible job-posting text, job metadata, and bounded verified job content in embedded frames. Standard form values, editable answers, file uploads, and hidden content are excluded. Public page text can itself contain personal information, so those exclusions are not a guarantee about everything a website displays.

How the information is used

The extension uses this information only to recognize the vacancy being viewed, apply its sponsorship and eligibility rules, show quoted evidence, remember settings, and create a report when you explicitly ask to download one. Findings describe source wording, not personal immigration eligibility.

Local scan text and findings stay in tab memory and are replaced when you navigate or rescan. They are not automatically sent to the developer and are not used to build or upload a browsing history. You can pause scanning everywhere, disable an individual site, or further restrict access with Chrome's site-access controls.

Network access and recipients

A narrowly matched Ashby application may fetch the same vacancy's official overview from the same website when the application page is missing its description. The website hosting that overview receives the ordinary web request. Extracted text is not sent to an analysis service. The active extension has no mechanism for developer collection, analytics, advertising, sale, or unrelated third-party transfer.

Saved settings and retention

Chrome local storage saves whether scanning is paused, disabled site names, and whether onboarding was dismissed. Preferences saved for removed features may remain stored but are ignored. Settings remain until you change them, clear extension data, or uninstall the extension. Uninstalling removes extension storage.

Optional incorrect-result reports

A report is created only when you choose to download it. It includes role details, findings, quoted evidence, scan time, and the page address after its query, fragment, username, and password are removed. It excludes the full extraction and form answers. Nothing is automatically submitted. The file stays wherever you save or share it, and you control its deletion.

Company research

Company research is deferred and inactive in version 0.6.0. The extension does not send employer or role details to a research service, fetch company policy pages, or send search queries to a provider. Research code retained elsewhere in the project is not used by the active extension.

Limited Use

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Future changes to data handling require updated disclosures.

Questions and changes

Contact the publisher through the support page. Material changes to the extension's data handling will be reflected in an updated policy and effective date.
